# EXPERIMENT 2: LIBRARY MANAGEMENT SYSTEM
### NAME: PRADEEPA B
### REG NO: 212225040308
# AIM:
To design and develop UML diagrams for a Library Management System using StarUML to represent its structure, functionality, and interactions.

# SRS (PROCEDURE):
1. Identify the system requirements and the four main actors: Admin, Student, Librarian, and Supplier.
2. Create a Use Case Diagram to represent the interactions between the actors and the system.
3. Draw a Class Diagram to represent the classes, attributes, operations, and relationships.
4. Develop a Sequence Diagram to illustrate the order of interactions between objects.
5. Create an Activity Diagram to represent the workflow of library operations.
6. Draw a Package Diagram to show the organization of the system into packages.
7. Create a Communication Diagram to represent interactions between objects using numbered messages.
8. Verify all six diagrams for correctness and consistency.
